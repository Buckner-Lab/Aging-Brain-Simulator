SuperAger and Maintainer Analysisv104_SuperAgers

Built 24 November 2026 on version 104 · in FavoriteSimulatorStageAdditions

This is an example of a modified simulator that used the Imagine function to build a bespoke stage. The stage explores how simulated participants are selected by various SuperAger and Maintainer criteria that are used to identify successful agers in the literature, including (1) how and when the different selection rules converge, (2) how they bias to select individuals with high baseline function, and (3) how measurement error influences misclassification differentially between rules.

Alzheimer’s Disease Clinical Trial Analysisv104_ADClinicalTrials

Built 25 November 2026 on version 104 · in FavoriteSimulatorStageAdditions

This is another example of a modified simulator that used the Imagine function to build a novel stage. The stage simulates the effects of an anti-amyloid therapy in a clinical trial, using the extended AD cascade. The default opens to show an approximation of the Lecanemab trial. Note you will need to click on the “Simulate full-size trial” to see the full sample, which will take 20-30 seconds. You can contrast that trial with one that recruits at an earlier clinical and pre-clinical stage, and see how power to detect an effect is severely impacted.

Simulator versions 1 to 104

The files are in HistoricalSimulatorVersions. Each file is the simulator as it was published at that version, named as it was when it was built: Parallax for versions 1 to 77, LifeBrain Simulator for versions 78 to 86 and AgingBrain Simulator for versions 87 to 104. Each name ends in the version's date from the version list. Where a version was published more than once, the file is its last publish. Every file opens on its own in a browser. Of historical note, the name Parallax was used initially because the simulator allowed a user to view the same simulated lives from many different vantage points. The functionality still exists, but the simulator is now named the AgingBrain Simulator to make clear the target of the simulator.
